# Bundled fonts

Each theme's face lives in `app/src/main/res/font/theme_*.ttf`. They come from github.com/google/fonts.
They were pinned to one weight and subset to the characters the app shows. Subsetting modifies a font, so per the
SIL Open Font License each file is renamed to its resource name and does not use any Reserved Font Name.
